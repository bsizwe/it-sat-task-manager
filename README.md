# Moola - AI-Powered P2P Lending

AI-powered peer-to-peer lending platform for South Africa. Borrow. Lend. Grow Together.

## Features

- Modern React-based fintech application
- AI-powered lending algorithms
- Progressive Web App (PWA) capabilities
- Multi-language support for South African languages
- SEO optimized with structured data
- Accessibility compliant design
- Security-focused implementation

## Tech Stack

- React with TypeScript
- Vite build tool
- Modern CSS with custom properties
- Service Worker for offline functionality
- Responsive design with Tailwind-style classes

## Getting Started

This project uses Vite as the build tool and expects React components in the `/src` directory.

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
